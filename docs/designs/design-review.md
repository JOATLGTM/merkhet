## Journey storyboard (accepted state)

| Step | User does | User feels | Plan specifies |
|---|---|---|---|
| 1 | Opens the board | Oriented | Existing page title and nav; collapsed nav keeps Sign out (D32) |
| 2 | Drags or keyboard-moves a card | In control | Keyboard drag and Move to… (D30, D36); card lands at once (performance plan) |
| 3 | Opens a project and edits fields | Confident | Visible focus underline and labels (D33) |
| 4 | Uploads a contract or records a sign-off | Reassured | Per-button pending labels (D20); Clear asks first (D24) |
| 5 | Puts a project on hold | Unhurried | In-app popover (D23); a true success message only (D18) |
| 6 | Hits a database hiccup | Not alarmed | In-frame error screen with Try again (D19) |
